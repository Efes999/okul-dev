# Sprint 4 React frontend

Bu klasör `kampus-etkinlik/` repository köküne, **Sprint3 klasörüyle aynı seviyeye** konur. Bu ZIP içindeki `Sprint3/` dosyalarının kaynakları kullanıcı tarafından sağlandı.

## Windows PowerShell / VS Code terminal
```
node -v
npm -v
cd frontend
npm install
npm run dev
```
Adres: http://localhost:5173

Son kontroller:
```
npm run test
npm run build
npm run preview
```
Vercel Settings → Root Directory: `frontend`, Framework Preset: `Vite`.
Sadece bu frontend klasörünü mevcut projene eklersen root README'yi de elle güncelle: ilk satıra Vercel canlı URL.
